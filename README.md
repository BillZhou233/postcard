# postcard

这个仓库存放由我拍摄的照片制作成的明信片。以 PNG 原图 + SVG 可直接输出版本分发，您可以使用 Inkscape 软件将 SVG 按照厂商提供的 DPI 输出为图片进行自印。

如果您有针式打印机，定做时文本面可以留空，然后全部由打印机打印。如果您使用手工编写，文本面也建议留空以同时适应国内/国际寄件的不同需求。
